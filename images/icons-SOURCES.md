The portfolio uses unmodified SVG icon paths from Font Awesome Free 6.7.2.

Source: https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs

- Brand icons: `brands/github.svg`, `brands/linkedin.svg`, `brands/whatsapp.svg`.
- Interface icons: `solid/bars.svg`, `solid/xmark.svg`, `solid/arrow-down.svg`, `solid/arrow-up.svg`, `solid/arrow-up-right-from-square.svg`, `solid/envelope.svg`, `solid/download.svg`, `solid/paper-plane.svg`, `solid/phone.svg`.
- E-Vote illustration: `solid/check-to-slot.svg`.

Icons are combined into `icons.svg` as reusable SVG symbols. The E-Vote artwork embeds the same standard check-to-slot path, with title text and a background.
